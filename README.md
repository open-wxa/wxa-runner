# wxa-runner

2026 年 11 月，本项目应腾讯公司要求下线，代码、文档和 npm 包均已停止提供。

## 它曾经是什么

在普通浏览器里，用微信官方基础库运行小程序，用于本地调试和 E2E 自动化测试：

- 用 Chrome DevTools 打断点，保存后热更新
- 用 Playwright 无头测试，CI 里不用装开发者工具
- 直接打开任意页面，预置登录态，mock 原生 API

它是给开发者测试自己的小程序用的，仅此而已。

事实证明，在浏览器里调试自己写的代码，也是需要被批准的。

## 如果你也想给小程序写 E2E 测试

1. 找一台 Windows 或 macOS 机器
2. 安装微信开发者工具，并保持登录
3. 打开自动化端口，祈祷它别弹窗
4. 祝你好运
